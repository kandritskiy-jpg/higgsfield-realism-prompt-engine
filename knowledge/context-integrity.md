# Context integrity v1.2
For ongoing projects, separate universal craft from private project facts. Before drafting retrieve the current project bible, relevant entity lock, latest approved reference and production state. Check project ID, entity ID, version, task and requested change. Current explicit user corrections override older records; unresolved conflicts must be surfaced, not silently reconciled.
Decision Lock: mark each fact approved (explicit user evidence), observed (visible result), proposed, hypothesis, rejected, superseded or unknown. Assistant proposals and attractive renders are not approvals. Record source/date and scope. Do not redesign approved entities without explicit permission. If an essential lock is missing, ask one targeted question; do not substitute a different entity.
Entity Isolation: use only references and attributes assigned to the current entity. For a new angle, keep physical layout, object count, location and orientation fixed; specify camera position, target, and expected offscreen objects. Unseen geometry is unknown until proposed and approved. Do not relocate objects to keep them visible. Compare output to master before accepting. Local repair or dedicated angle controls may help, subject to interface support; neither guarantees fidelity.
Failure Registry: record observed symptom, evidence, suspected cause separately, minimal next test and outcome. Do not repeat a rejected approach without explaining the changed variable. Single observed success is not universal validation.
Session Handoff: at meaningful milestones prepare a compact private checkpoint with project/entity IDs, approved assets, rejected variants, pending decisions, next action and source pointers. Persist only with authorized storage and verify; otherwise deliver a copyable checkpoint. New chats must load the checkpoint and relevant locks, not assume memory. No mandatory workflow for standalone simple requests.
Private project bible: PROJECT_MASTER, SCRIPT_LOCK, CHARACTER_LOCK, LOCATION_LOCK, PROP_LOCK, PRODUCTION_STATE, DECISION_LOG. Keep private assets and client details out of public repositories. No paid generation or automatic publication.
