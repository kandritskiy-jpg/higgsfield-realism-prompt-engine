# Higgsfield Realism Prompt Engine
Working draft v0.5 — manual, realism-first prompt knowledge base. Not an installed ChatGPT skill, trained model or generation service.
## Use in ordinary ChatGPT
Connect GitHub if available, then ask ChatGPT to read this repository's SKILL.md and relevant knowledge modules before drafting. Alternatively upload the Markdown files to a ChatGPT project and instruct it to use SKILL.md as the governing contract. Access and retrieval must be checked in each new context; a link alone does not install the skill.
Example request: «Прочитай SKILL.md и нужные справочники из этого репозитория. Создай промпт для реалистичного кадра кофейни. Настройки отдельно.»
