# Higgsfield Realism Prompt Engine
v1.1 continuous learning — manual, realism-first prompt knowledge base. Not an installed ChatGPT skill, trained model or generation service.
## Use in ordinary ChatGPT
Connect GitHub if available, then ask ChatGPT to read this repository's SKILL.md and relevant knowledge modules before drafting. Recommended: download [HIGGSFIELD_ENGINE_v1.1.md](HIGGSFIELD_ENGINE_v1.1.md), upload it to a ChatGPT project, and paste [CHATGPT_PROJECT_INSTRUCTIONS.md](CHATGPT_PROJECT_INSTRUCTIONS.md) into project instructions. The portable snapshot includes all nine knowledge modules, master rules and source records. No automatic installation. Access and retrieval must be checked in each new context; a link alone does not install the skill.
Example request: «Прочитай SKILL.md и нужные справочники из этого репозитория. Создай промпт для реалистичного кадра кофейни. Настройки отдельно.»

## Status
Six realism modes, optional creative direction, model routing, reference handling, artifact repair and sound. English copy-ready prompts, Russian conversation by default. User selects all generation controls. No paid generation or empirical media validation. Model capabilities must be verified against current UI. Public repository: do not store confidential client material. No blanket project license selected.
