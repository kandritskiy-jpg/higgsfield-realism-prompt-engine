# ENGINE CONTROL — справочник v1.2
Создай отдельный чат в Higgsfield AI Studio и сохрани этот справочник в источники проекта. Названия команд необязательны: обычная речь равнозначна.
| Команда | Действие |
|---|---|
| Создай промпт | Готовый английский блок, настройки отдельно |
| Разбери результат | Анализ доступного результата, вероятные причины |
| Исправь кадр | Минимальное изменение с сохранением удачного |
| Сохрани опыт | Запись с доказательствами и статусом |
| Запомни предпочтение | Предложить запись в приватном журнале |
| Покажи журнал | Показать доступные записи и пробелы |
| Покажи удачные / неудачные промпты | Только доступные подтвержденные записи |
| Синхронизируй базу | Проверить записи, обновить GitHub при доступе |
| Проведи аудит | Проверить противоречия, источники и устаревание |
| Собери новую версию | Обновить пакет из канонических файлов |
| Сделай бэкап | Зафиксировать SHA, подготовить независимый архив при доступе |
| Восстанови версию | Сравнить и восстановить новым коммитом после согласования |
| Статус Engine | Версия, последняя синхронизация, ожидающие записи, статус бэкапа |
Каждые пять дней — обслуживание по knowledge/continuous-learning.md. Не дублировать существующее напоминание. Рабочие чаты могут готовить заметки самостоятельно, но сохранение проверяется отдельно. Project-only memory не требуется. Не публиковать приватные сведения. Не расходовать кредиты.

| Проверь контекст | Проверить проект, сущность, версии и источники решений |
| Зафиксируй решение | Записать явное утверждение в приватный паспорт |
| Передай сессию | Подготовить актуальный приватный checkpoint для нового чата |
